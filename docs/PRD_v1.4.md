# 班级作文工作台 PRD v1.4.0

## 1. 版本结论

`v1.3.0` 的自动化功能基本完成，但一期仍需老师用真实手机、电脑和投影完成验收。二期优化以一期验收通过为开发门槛，自动化测试不能替代真实识别质量和教师工作流验收。

本版本在保留拍照、识别、待校对、定稿、成册、投屏和分享基本盘的前提下，降低名单导入和逐人上传成本，并统一校对、排序和展示口径。

## 2. 用户流程

1. 老师登录后下载 Excel/CSV 模板，上传名单，预览字段匹配、新增、更新、重复和错误行，确认后整批写入。
2. 拍照上传页按学号自然排序显示 4/5 列学生网格，支持姓名/学号搜索、多选和逐人上传队列。
3. 作文进入识别中、待校对、已定稿或失败状态；失败稿可重跑。
4. 校对页对照原片、识别原文和定稿文字，评语与评分随稿保存；定稿和识别对照共用校对草稿，原始识别数据只读。
5. 已定稿作文进入成册、精选、投屏、表彰、成长档案和家长分享。

## 3. 功能需求

### FR-01 学生导入

- 提供 `.xlsx` 和 `.csv` 下载模板。
- 自动识别“学号/学生学号/学号编号”和“姓名/学生姓名”等表头。
- 上传后只预览，不写库；确认接口整批事务写入，错误行存在时拒绝整批。
- 学号唯一；已存在学生更新姓名并恢复启用，学生列表按学号自然排序。
- 保留原 JSON 批量导入接口兼容脚本和旧客户端。

### FR-02 选择学生与连续上传

- 390px 及以上默认五列，更窄设备四列；网格可纵向滚动。
- 每项显示姓名、学号和勾选框；搜索后保留当前选择并定位匹配学生。
- 多选后每位学生独立提交照片，成功后进入下一位；照片不会跨学生归属。

### FR-03 校对与展示

- 桌面端原片约 36%，校对区约 64%；左下评语区与原片列同宽，评分、评语、保存状态和放大按钮集中展示。
- 定稿文字、识别对照和老师评语均可独立放大/还原；识别对照独立滚动，手机端整页纵向滚动。
- 识别对照继续保留问号/虚线标注、存疑计数和点击定位原片。
- 校对保存只写 `final_text`、评语、评分等既有字段；`engine1_text`、`engine2_text`、`diff_json` 只读。
- 数据库存自然段；展示层按 25 字一行处理，不改数据库正文。

### FR-04 精选、成册与排序

- 成册、预览、单篇版式和投屏统一支持按学号、姓名、评分、精选优先排序。
- 精选优先时先排精选，精选内部评分降序，同分按学号；未评分排最后。
- 右侧作文集预览和单篇版式列表共用排序结果，单篇列表独立纵向滚动。
- 模板共五套，新增“纸上阅读风”；精选只影响排序、标识和榜单，不改正文。

### FR-05 讲评投屏与表彰

- 投屏支持上一页/下一页与上一篇/下一篇，第一篇最后一页可进入下一篇。
- 桌面端目录显示姓名、学号、精选状态，支持学号和精选优先排序并可跳转；手机端使用隐藏/抽屉式目录。
- 投屏复用定稿的 25 字展示规则；未定稿但有识别文字的作文显示“识别初稿”标识，无文字稿明确说明。
- 表彰提供佳作榜、进步榜、星级榜和投影态；星级榜不显示分数和名次。

### FR-06 成长档案与分享

- 成长档案只收已定稿作文，每篇提供返回校对入口。
- 家长分享主推“整期全部”和“仅精选”，保留单学生接口兼容；公开页只展示已定稿正文、评语和星级，不展示学号、评分和教师管理入口。

## 4. 非功能与不变量

- 不改变识别原文、`diff_json` 和既有定稿保存接口语义。
- 版本唯一来源为 `backend/app/__init__.py` 的 `__version__`，本版本为 `1.4.0`。
- 手机 390×844、844×390，桌面 1366×768、1920×1080 不产生横向溢出。
- 错误、重复导入、未定稿导出、无精选海报和失效分享链接均给出可操作提示。

## 5. 分阶段与验收门禁

0. 一期真实验收：导入、拍照、识别、校对、定稿、精选、成册、投屏和分享全流程。
1. 校对页与学生导入：先验证教师核心闭环。
2. 网格选人与连续拍照：验证 5 人、45 人、重复上传。
3. 精选、成册与排序：验证四种排序、第五套模板和大量作文滚动。
4. 投屏、榜单和分享：验证目录、翻篇、格式复用、投影态和范围收口。
5. 全链路审查：执行后端 `pytest/ruff/mypy`、前端 `vitest/typecheck/eslint/build`、四档视口探针和真人验收。

只有阶段 0 的真实验收通过后，才将后续阶段视为可进入开发；任何自动化绿灯都不能单独替代该门禁。
